# MyGameEngine

A C++ OpenGL game engine/editor project focused on scene editing, component-based game objects, asset references, serialization, and real-time rendering.

## Highlights
- Editor UI with Scene, Hierarchy, Inspector, Asset views
- GameObject and Component architecture
- Transform and rendering-related components
- JSON scene serialization
- Asset reference and material system
- OpenGL rendering with shader/material assets
- CMake + Visual Studio workflow

## Tech Stack
C++, CMake, OpenGL, GLFW, Dear ImGui, glad

## Build
1. Clone the repository.
2. Open `CMakeProject1` with Visual Studio 2022.
3. Select an x64 debug preset.
4. Build and run `CMakeProject1`.

## Project Structure
- `CMakeProject1/CMakeProject1/src` - engine/editor source code
- `CMakeProject1/CMakeProject1/assets` - sample scene, materials, shaders, vertex assets
- `CMakeProject1/CMakeProject1/external` - third-party dependencies
